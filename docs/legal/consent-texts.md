# Consent texts (plan 0.3a, 7.6) - DRAFT, versioned

Rules: unticked by default, one purpose per checkbox, withdrawable anytime, each grant stored in
`consents` (user, purpose, version, timestamp, truncated IP). Any wording change = new version
and re-ask.
