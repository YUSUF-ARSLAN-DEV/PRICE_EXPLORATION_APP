- [ ] `.qa` domain registered, in company name

- [ ] Cookie consent working; no analytics before consent
- [ ] DPIA + ROPA signed; sub-processor register published; DPAs signed
- [ ] Every live source is `green` in the Source Registry with `approval.md`
- [ ] Takedown inbox monitored; kill-switch tested
- [ ] Breach runbook rehearsed (tabletop), NCGAA contacts verified
- [ ] Alcohol/tobacco exclusion enforced in DB view and tested
- [ ] Price disclaimers + "last updated" on every price
- [ ] Sponsored-content labelling rule live (or no sponsored content)
- [ ] Independent pen test: no open High/Critical
- [ ] Deletion + export flows tested end-to-end
